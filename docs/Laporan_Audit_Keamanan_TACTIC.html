2. Evaluasi Komprehensif Berdasarkan 10 Ruang Lingkup Audit
1. Autentikasi & Otorisasi RBAC (Role-Based Access Control)
Remediasi Selesai
File Terkait: application/controllers/Auth.php:177, application/controllers/UserManagement.php

Evaluasi & Mitigasi:

  • Session Fixation (HIGH-02): Telah dimitigasi dengan menambahkan $this->session->sess_regenerate(TRUE); tepat setelah password/LDAP diverifikasi berhasil pada Auth::login().
  • RBAC & Privilege Escalation: Controller admin (UserManagement, HakAkses, TipeKendaraan, Restore) memiliki kontrol multi-role yang ketat pada level konstruktor. Pengguna biasa tidak dapat mengakses fitur administratif.
  • Endpoint Publik: Endpoint publik dibatasi hanya pada form login dan endpoint API terlindungi token timing-attack safe hash_equals().
2. Validasi Input, SQL Injection & Cross-Site Scripting (XSS)
Status: AMAN
File Terkait: Seluruh Model pada application/models/ & View pada application/views/

Hasil Analisis:

  • SQL Injection: Seluruh model memanfaatkan Active Record / Query Builder. Pada raw SQL queries, seluruh input string telah diescape dengan $this->db->escape(), parameter pencarian menggunakan $this->db->escape_like_str(), dan ID di-cast ke (int).
  • XSS: Output data pengguna pada view telah diescape secara konsisten menggunakan html_escape().
  • Command Injection: Bebas dari pemanggilan fungsi eksekusi sistem berbahaya (exec, shell_exec, system).
3. Keamanan Unggah Berkas (*File Upload Security*)
Remediasi Selesai
File Terkait: uploads/.htaccess, application/controllers/Pengajuan.php

Evaluasi & Mitigasi (HIGH-03):

File uploads/.htaccess telah diperbarui ke aturan modern Apache 2.4 (Require all denied) yang memblokir seluruh varian ekstensi skrip yang dapat dieksekusi (.php*, .phtml, .phar, .inc, .sh, .pl, .py, .cgi, .exe, .shtml, .pht, .asp, .jsp) serta menonaktifkan directory listing (Options -Indexes -ExecCGI).

4. Paparan Data Sensitif & Kredensial (*Sensitive Data Exposure*)
Remediasi Selesai
File Terkait: application/config/app_env.php, database_env.php, .gitignore

Evaluasi & Mitigasi (CRIT-01 & MED-02):

Kunci enkripsi aplikasi telah dipindahkan ke app_env.php dengan key 256-bit kriptografis acak, dan kredensial database diisolasi ke database_env.php. Seluruh file environment rahasia telah terdaftar di .gitignore dan template .example.php telah disediakan.

5. Header HTTP & Perlindungan CSRF (*HTTP Headers & CSRF*)
Remediasi Selesai
File Terkait: application/hooks/SecurityHeaders.php, application/config/hooks.php

Evaluasi & Mitigasi (HIGH-01):

Sistem hooks telah diaktifkan secara global dan menginjeksi header: X-Frame-Options: SAMEORIGIN (mencegah Clickjacking), X-Content-Type-Options: nosniff (mencegah MIME sniffing), X-XSS-Protection, Referrer-Policy, dan Permissions-Policy.

6. Penanganan Password & Kredensial Pengguna
Remediasi Selesai
File Terkait: application/controllers/Profil.php:165, UserManagement.php:295

Evaluasi & Mitigasi (MED-01):

Algoritma hashing menggunakan standar modern BCRYPT native PHP. Validasi password baru telah diperketat mewajibkan minimal **8 karakter** dengan kombinasi huruf besar, huruf kecil, dan angka.

7. Dependensi & Library Pihak Ketiga
Status: AMAN
Komponen: CodeIgniter 3.1.13, Bootstrap 5.3, jQuery 3.6.0, DataTables 1.13.6, SweetAlert2

Seluruh library JavaScript dan stylesheet menggunakan versi stabil dan terisolasi secara lokal tanpa adanya pemanggilan dependensi pihak ketiga yang rentan terhadap known CVEs.

8. Kerentanan Logika Bisnis & IDOR (*Insecure Direct Object Reference*)
Status: AMAN
File Terkait: Pengajuan.php, Kendaraan.php

Operasi mutasi data (edit, hapus, soft delete) telah dilengkapi validasi kepemilikan departemen dan hak akses peran. Pengguna tidak dapat memanipulasi pengajuan milik departemen lain.

9. Perlindungan Brute-Force & Rate Limiting (DoS)
Status: AMAN
File Terkait: Auth.php:75-95, api/Laporan.php:20

Login terlindungi mekanisme database lockout (maks. 5 kegagalan -> lockout 5 menit). Endpoint API terlindungi rate limiting 30 req / 60 detik.

10. Jejak Audit & Logging (*Audit Trail*)
Status: AMAN
File Terkait: Tabel audit_log

Seluruh aksi kritis sistem (login, logout, delete, restore, approval) tercatat secara terstruktur ke tabel audit_log tanpa mencatat password pengguna.
